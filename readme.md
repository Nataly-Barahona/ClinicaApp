# EQUIPO 2 - Las SuperEstrellas ⭐⭐⭐⭐⭐ 

Desarrollo de Aplicacion de java de la **Clinica** que es un sistema de gestión de turnos que se desarrollado en **Java** aplicando los principios de la **Programación Orientada a Objetos (POO)**. Permite registrar pacientes y médicos, asignar turnos, consultar agendas y garantizar la persistencia de los datos entre ejecuciones utilizando archivos CSV.

Proyecto desarrollado para el **Hackathon de Generation**.

## Cómo Ejecutar el Proyecto en IntelliJ IDEA

paso 1: Clonar el repositorio para esto Abre tu terminal

paso 2: Abre IntelliJ IDEA.

paso 3: Si ya tienes un proyecto abierto dentro de IntelliJ:
Ve al menú superior y selecciona File → Open...
paso 4: En la ventana emergente de tu explorador de archivos, busca y selecciona la carpeta raíz del proyecto y haz clic en OK (o Open)
paso 5: En el panel lateral izquierdo de IntelliJ (Project Explorer), expande la estructura de carpetas haciendo clic en las flechitas
paso 6: Localiza el archivo de entrada del programa: Main.java
paso 7: Abre el archivo haciendo doble clic sobre él
paso 8: Haz clic en el pequeño ícono de reproducción verde (▶) que aparece al margen izquierdo de la línea donde se declara el método
paso 9: Una vez ejecutado, en la parte inferior de IntelliJ se abrirá automáticamente la pestaña Run (Consola).
Verás desplegado el menú principal de ClinicaApp con las 10 opciones de gestión y la opción 0 para salir
Haz clic con el mouse dentro del recuadro negro de la consola para escribir los números de las opciones y presiona Enter para navegar por el sistema.
